Veřejná API Shieldio

Tato stránka dokumentuje rozhraní dostupná bez přihlášení. Aktuální strojově čitelný seznam je v API katalogu podle RFC 9727.

Simulation Health API

Veřejné rozhraní pro kontrolu dostupnosti simulátoru. Je pouze pro čtení a nevyžaduje autentizaci.

Endpoint: GET https://simulation.shieldio.cz/api/health

Odpověď: HTTP 200 a JSON s klíči status (hodnota ok), app (identifikátor shieldio-simulation) a version (textová verze aplikace).

OpenAPI: simulation-openapi.json

Označení ok potvrzuje odpověď health endpointu, nikoli funkčnost všech částí simulátoru nebo externích služeb.

Přístup AI agentů

Veřejné MCP rozhraní Shieldio a dokumentace jsou dostupné anonymně bez vydávání přihlašovacích údajů. Podrobnosti o podporovaných postupech a omezeních uvádí auth.md pro AI agenty. OAuth registrace ani zápisová oprávnění nejsou aktuálně dostupné.
