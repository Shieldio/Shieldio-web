Ověření připojení k EduPage

Nejdřív ověříme, zda se Shieldio Learn dokáže bezpečně přihlásit. Teprve podle výsledku má smysl stavět další nástroje.

Jednorázový test

Údaje odejdou šifrovaně na stage server a odtud přímo do EduPage. Shieldio je neukládá a po testu zahodí i vzniklou relaci.

Co test zjistí

  • zda škola používá podporovaný způsob přihlášení,
  • zda EduPage přijme údaje a vytvoří relaci,
  • zda účet nevyžaduje CAPTCHA nebo druhý faktor.

Test zatím nestahuje známky, rozvrh ani osobní údaje.
