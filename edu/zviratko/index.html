Zvířátko na displeji: příprava hodiny

Před hodinou ověřte desku a nahrávání. Žákům pošlete jen krátký návod s blokovým programem.

Otevřít návod pro žáky

1. Připravte sestavenou desku

Projekt používá displej a dvě tlačítka na sestavené RED. Žáci k ní nepřidávají další displej ani rezistory. Senzor vzdálenosti a servo se v tomto programu nepoužívají. Ověřte revizi desky; veřejný osazovací přehled je určený pro V3, nikoli jako návod k osazení V4.

Technická kontrola: OLED SSD1306 128 × 64, I²C adresa 0x3C, SDA → A4, SCL → A5. Tlačítka 1/2 → D11/D12. Na RED jsou pull-up rezistory již osazené na desce; stisk znamená LOW. Při výměně modulu odpojte napájení a ověřte pořadí GND/VCC podle jeho popisků.

2. Ověřte nahrávání na školním účtu

Použijte desktopový Chrome nebo Edge a datový USB kabel. Safari přímé nahrávání přes Web Serial nepodporuje; pro hodinu přejděte do Chrome/Edge. Ponechte cíl Shieldio RED (klasické Nano s ATmega328P, 16 MHz). Pokud deska neodpovídá, v Pokročilý režim → Nastavení desky vyzkoušejte 115200 nebo starý bootloader 57600. Volba bootloader nepřepisuje. Postupujte podle prvního spuštění.

3. Knihovna a volitelný C++

Webový editor přidá ShieldioDisplay 0.3.0 automaticky. Pro základní hodinu nic neinstalujte. Při práci v Arduino IDE použijte tuto verzi nebo novější se stejným API; starší verze nemusí obsahovat Animal, Mood a face(). Zdroj a dokumentace knihovny.

Otevřít Arduino C++Stáhnout Arduino program (.ino)
Zobrazit celý program
// Shieldio RED: OLED SSD1306 128x64, SDA A4 / SCL A5, address 0x3C.
// Buttons D11/D12 have external pull-ups on RED; pressed = LOW.
#include <ShieldioDisplay.h>
ShieldioDisplay display;
using Animal = ShieldioDisplay::Animal;
using Mood = ShieldioDisplay::Mood;
Animal shownAnimal = Animal::Cat;
Mood shownMood = Mood::Sleepy;

void setup() {
  pinMode(11, INPUT);
  pinMode(12, INPUT);
  display.begin();
  display.face(shownAnimal, shownMood);
}

void loop() {
  // Button 2 has priority, matching the block starter.
  bool second = digitalRead(12) == LOW;
  bool first = digitalRead(11) == LOW;
  Animal animal = second ? Animal::Dog : Animal::Cat;
  Mood mood = second ? Mood::Surprised : first ? Mood::Happy : Mood::Sleepy;
  if (animal != shownAnimal || mood != shownMood) {
    display.face(animal, mood);
    shownAnimal = animal;
    shownMood = mood;
  }
  delay(100);
}

4. Přejímací zkouška před hodinou

  1. Nahrajte blokový program na každou používanou desku.
  2. Ověřte ospalou kočku, veselou kočku při tlačítku 1 a překvapeného psa při tlačítku 2.
  3. Obě tlačítka současně: má přednost tlačítko 2.
  4. Změňte psa na lva a znovu nahrajte. Pak vraťte původní program pro žáky.
  5. Zaznamenejte revizi desky a funkční nastavení bootloaderu. Kompilace sama nepotvrzuje funkci na hardwaru.

Diagnostika pro učitele

Prázdný displej: ověřte napájení, SDA/A4, SCL/A5 a adresu 0x3C. Tlačítko nereaguje: ověřte D11/D12 a stisk LOW. face() nahradí obraz ihned, další render() nepotřebuje. U vlastního textu knihovna podporuje ASCII bez české diakritiky. Zvířecí tváře byly dříve ověřeny na OLED; konkrétní sestavu a tento projekt přesto ověřte před výukou.
