RED naprogramuješ přímo tady.

V editoru Shieldio sestavíš bloky nebo napíšeš Arduino C++. Jednoduchý režim je pro RED; pokročilý přidává klasické Uno R3 a Nano. V Chrome nebo Edge nahraješ program přímo přes USB.

Co je v editoru

V jednoduchém režimu najdeš pod Shieldio RED kategorie LED, Tlačítka, Vzdálenost, Servo, Zvuk a Displej. Čekání a délka tónu jsou v sekundách. Displej sdružuje text, zvířátka i kreslení; text píšeš přímo do bloku. Pokročilý režim přidává matematiku, číselné proměnné a vlastní C++.

Vedle bloků je ruční Arduino C++. Kompilátor běží v prohlížeči; zdrojový kód se neposílá na server ke zpracování. Při prvním použití se stáhnou nástroje a knihovny.

Kompilace vytvoří HEX. Nahrávač zkontroluje čip, zapíše program a přečte data zpět pro ověření. Úspěšné automatické testy nenahrazují kontrolu konkrétní desky, kabelu a školního počítače.

ShieldioDisplay 0.3.0 včetně kočky, psa a lva je přibalená společně se Servo, Wire, SPI, Adafruit GFX a SSD1306. Vlastní hlavičkovou nebo C++ knihovnu pro AVR načteš ze složky. C, assembler a předkompilované knihovny zatím importovat nejdou.

V nabídce Deska v pokročilém režimu zvolíš Shieldio RED, Arduino Nano nebo Arduino Uno R3 s ATmega328P. Výběr mění kompilaci, dostupné analogové piny i nahrávání. Green, Yellow a PRO zůstávají koncepty; Uno R4, Nano Every, Nano 33 a ESP32 tento editor nepodporuje.
