RED naprogramuješ přímo tady.

V editoru Shieldio sestavíš bloky nebo napíšeš Arduino C++. Program se přeloží pro Nano a v Chrome nebo Edge se nahraje přes USB.

Co je v editoru

V blocích vybereš modul RED: LED, tlačítka, ultrazvuk, servo, bzučák nebo OLED. Čas a další hodnoty píšeš přímo do políček; místo čísla můžeš vložit i výpočet. Pokročilá nabídka přidává matematiku a číselné proměnné.

Vedle bloků je ruční Arduino C++. Kompilátor běží v prohlížeči; zdrojový kód se neposílá na server ke zpracování. Při prvním použití se stáhnou nástroje a knihovny.

Kompilace vytvoří HEX. Nahrávač zkontroluje čip, zapíše program a přečte data zpět pro ověření. Úspěšné automatické testy nenahrazují kontrolu konkrétní desky, kabelu a školního počítače.

ShieldioDisplay je přibalená společně se Servo, Wire, SPI, Adafruit GFX a SSD1306. Vlastní hlavičkovou nebo C++ knihovnu pro AVR můžeš načíst ze složky. C, assembler a předkompilované knihovny zatím importovat nejdou.

Univerzální bloky pracují s vlastními piny, ale kompilace a nahrávání zatím míří na klasické Nano s ATmega328P. Green, Yellow, PRO, ESP32 ani jiné varianty Nano tímto nepřibývají mezi podporované desky.
