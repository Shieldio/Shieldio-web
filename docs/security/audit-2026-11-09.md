# Bezpečnostní audit Shieldio — 9. listopadu 2026

## Rozsah a úroveň jistoty

Ruční statická kontrola hlavního `shieldio.cz` (Cloudflare Worker, veřejný obsah, editor RED, Web Serial, vyhledávání a formuláře), navazujících Learn/ESP32 integrací a GitHub Actions. Kontrola současného kódu a konfiguračních souborů; **nejde o penetrační test všech produkčních hostů ani audit Cloudflare účtu**. Konkrétní HTTP hlavičky na produkci ověřuje samostatný deploy workflow po nasazení. Nebyly prováděny škodlivé požadavky, spouštění cizího firmware ani zasílání formulářů.

## Pozitivní zjištění

- Arduino nahrávání vyžaduje výslovnou uživatelskou akci a povolení Web Serial prohlížečem.
- `parseHex` ověřuje kontrolní součet, adresy, překrytí, EOF a nepřekračuje aplikovatelnou flash 30 720 B.
- Před zápisem se kontroluje podpis ATmega328P a firmware se po nahrání zpětně ověřuje; při chybě se port uvolní.
- Kompilace Arduino C++ běží ve Web Workeru a čte omezený počet a velikost uživatelských knihoven; běží s časovým limitem.
- Text nahrávaného programu i chyby kompilátoru se v UI vkládají převážně jako `textContent`.
- Learn přístupová brána sama používá ochranné cookie `Secure`, `HttpOnly`, `SameSite=Lax` a odpověď `no-store`; to však neochrání materiály současně zveřejněné mimo bránu.

## Další postup

1. Rozhodnout, zda obsah Learn beta má být pouze neveřejně *procházený*, nebo skutečně důvěrný. Pokud druhé, nepokládat bránu za dostatečné řešení a přesunout materiály mimo veřejné soubory.
2. Vendorizovat Blockly a AVR toolchain včetně manifestu sha256 a nezávislých aktualizačních testů. Nepřestavovat kompilátor bez regresních testů.
3. Auditovat skutečné cloudové zásady WAF, formulářovou ochranu, přístupová práva deploy tokenu a GitHub branch protection; tyto účty nejsou ověřené samotným čtením repozitáře.
4. Připravit plnou CSP se samostatným kompatibilitním testem všech interaktivních webů. Nenasazovat obecné `script-src 'self'` naslepo.
5. Opakovat automatické kontroly HTTP odpovědí a provést ruční bezpečnostní test v prohlížeči.

Žádný výsledek tohoto auditu není důkazem absolutní bezpečnosti, pouze popisuje uvedené zkontrolované vrstvy.
