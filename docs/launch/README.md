# Co ještě doložit před launchem

Aktuální web představuje vývojový projekt. Formulář RED zjišťuje nezávazný zájem; neuzavírá prodej. Právní stránky popisují tento stav.

## Provoz formulářů

- [ ] V účtu Web3Forms ověřit použitý tarif, uchování zpráv a postup výmazu. Veřejné zásady služby uvádějí obecné maximum tři roky; zásady Shieldio uvádějí pro vlastní kopie 12 měsíců od poslední komunikace. Nastavení musí odpovídat zveřejněným informacím.
- [ ] Doložit zpracovatelské podmínky a mechanismus případného předání mimo EHP u používaných dodavatelů. Obecný odkaz na jejich zásady není potvrzení konkrétního nastavení účtu.
- [ ] Ověřit, kdo má přístup k doručeným zprávám a kdo vyřizuje žádosti o výmaz.
- [ ] Ověřit pole, přístupy a dobu uchování externího školního dotazníku v Microsoft Forms.
- [ ] Posoudit účely místního ukládání a případnou potřebu souhlasu podle pravidel pro cookies a obdobné technologie. Zdrojový kód sám právní titul nedokládá.

## Obsah a hardware

- [ ] Dodat ověřený kusovník a zapojení aktuální revize PCB. Veřejný osazovací návod je pro V3; výjimky V3 nepřenášet na V4/V5.
- [ ] Dodat detailní fotografie hodnot a polarity součástek i skutečné výsledky projektů.
- [ ] Projít návody na fyzické desce a ověřit servo, senzor, LED i OLED.
- [ ] Vyzkoušet první program s člověkem, který Shieldio nezná: najde první akci, rozliší kontrolu od nahrání a pozná výsledek na desce.

## Pokud začne prodej

Před zapnutím objednávek připravit údaje skutečného prodávajícího, ceny a platby, dodání, informace o právech spotřebitele, reklamacích a odstoupení a podklady bezpečnosti výrobku. Současné podmínky používání webu tento krok nenahrazují. Teprve s ověřenými údaji upravit formuláře, texty a strukturovaná data.
