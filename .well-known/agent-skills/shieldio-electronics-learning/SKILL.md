# Learn electronics with Shieldio

Use this skill when teaching or studying introductory electronics using Shieldio's publicly available explanatory materials.

## Find a relevant lesson

- [Electronics lesson hub](https://shieldio.cz/instructions/jak-to-funguje/): topic overview.
- [Ohm's law](https://shieldio.cz/instructions/jak-to-funguje/ohmuv-zakon/): relationships between voltage, current, and resistance.
- [Diodes and LEDs](https://shieldio.cz/instructions/jak-to-funguje/dioda-a-led/): diode behaviour and LED fundamentals.
- [Capacitors](https://shieldio.cz/instructions/jak-to-funguje/kondenzatory/): basic types and function.
- [PWM](https://shieldio.cz/instructions/jak-to-funguje/pwm/): controlling LEDs and servos.
- [Buttons and debounce](https://shieldio.cz/instructions/jak-to-funguje/tlacitka-a-debounce/): pull-ups and reliable switch input.
- [Ultrasonic measurement](https://shieldio.cz/instructions/jak-to-funguje/ultrazvuk/): HC-SR04 sensing.
- [Printed circuit boards](https://shieldio.cz/instructions/jak-to-funguje/pcb/): PCB basics.

## Teaching workflow

1. Select the topic and learner level, then read the relevant lesson rather than inventing product-specific details.
2. Explain the principle in plain language, with units and a small worked example where useful.
3. Connect the principle to a documented [RED project](https://shieldio.cz/instructions/baseline/red/) if the learner has that hardware.
4. For school use, consult [teacher preparation](https://shieldio.cz/company/pro-ucitele.html) and the [barrier lesson plan](https://shieldio.cz/company/metodika-zavora.html).
5. Mark any suggested extensions as your own ideas, not published Shieldio instructions.

## Boundaries

- Treat electricity and wiring as physical activities requiring basic supervision and a verified schematic.
- Do not assume RED V3 assembly details are valid for V4.
- Do not imply the RED board is currently available for purchase.
- Agent-readable Markdown can be requested with `Accept: text/markdown` on public Shieldio HTML pages; the regular browser receives HTML.
