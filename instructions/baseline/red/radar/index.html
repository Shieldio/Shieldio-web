POSTAV S RED

Ultrazvukový radar

Rozšiř digitální metr o pohyb. Servo projíždí úhly a displej ukazuje naměřené body ve společném měřítku.

ZapojeníProgramOvěřeníPřehled součástek

Navazující experiment, 45–60 minut bez výroby držáku. Nejdřív zprovozni digitální metr. K jeho součástkám přidej servo SG90, držák HC-SR04 na páku serva, pružné propojovací vodiče a vhodné napájení. Hotový radarový držák není v tomto návodu dodaný. Senzor musí být vyjmutý z pevné patice a otáčet se se servem.

Technicky jde o ultrazvukový skener (sonar), ne rádiový radar. HC-SR04 vrací odraz v určitém směru; široký zvukový svazek neumí přesně rozlišit několik objektů vedle sebe. Zobrazení je orientační řez okolím, ne přesná mapa místnosti.

1. Zapojení a mechanika

Shieldio RED
ModulSignály
HC-SR04VCC → 5 V · GND → GND · TRIG → D7 · ECHO → D8
OLED SSD1306SDA → A4 · SCL → A5 · VCC/GND
Servo SG90SIGNAL → D9 · +5 V · GND

Na sestavené RED jsou signály propojené cestami na PCB. Použij označené patice; vodiče navíc potřebuje až otočný senzor radaru. Moduly připojuj s odpojeným napájením a ověř pořadí vývodů, zvlášť GND/VCC u OLED.

Servo pevně upevni. Nejprve jej níže uvedeným kalibračním programem nastav na 90°. Potom odpoj napájení a nasaď páku s držákem tak, aby senzor mířil dopředu. Vodiče veď volně a vyzkoušej, že při rozsahu 30–150° nic nenaráží ani netahá za konektor. Hřídel serva neotáčej silou.

Kalibrační program: servo drží 90°
#include <Servo.h>
Servo servo;
void setup() { servo.attach(9); servo.write(90); }
void loop() {}

Servo napájej stabilním zdrojem podle parametrů konkrétního serva. Pokud použiješ externích 5 V, připoj napájecí vodič serva přímo k tomuto zdroji a spoj jeho GND s GND desky; k RED pak vede signál D9 a společná zem. Nespojuj zároveň externí +5 V s USB napájením RED. Při restartech desky nebo cukání nejdřív prověř napájení a volný chod mechaniky.

2. Nahraj skenovací program

Klikni na Otevřít program v editoru. Ukázka se načte do Arduino C++; vyber USB port RED a nahraj ji. Adafruit GFX a SSD1306 i Servo jsou přibalené. OLED má rozlišení 128 × 64 a adresu 0x3C. Pokud použiješ vlastní sériový monitor na 115200 baud, před dalším nahráváním ho odpoj.

Program projíždí 30–150° po 5°. Po každém pohybu čeká 120 ms a pak měří. Na OLED je nejnovější bod pro každý úhel; neplatný nebo vzdálenější odraz předchozí bod vymaže. Obraz se obnovuje postupně, proto se pohybující předmět může objevit na více místech během jednoho průchodu.

// Shieldio RED: ultrasonic scanner, NOT a radio radar.
// Requires HC-SR04 mounted on the servo, flexible wires and adequate servo power.
#include <Wire.h>
#include <Servo.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <math.h>

const uint8_t TRIG_PIN = 7, ECHO_PIN = 8, SERVO_PIN = 9;
const uint8_t OLED_ADDRESS = 0x3C;
const int MIN_ANGLE = 30, MAX_ANGLE = 150, STEP_ANGLE = 5;
const uint8_t POINT_COUNT = (MAX_ANGLE - MIN_ANGLE) / STEP_ANGLE + 1;
const uint16_t RANGE_CM = 100;
const float RADIUS_PX = 45.0f;
// Set to -1 if the servo's physical left/right direction is mirrored.
const int8_t X_DIRECTION = 1;
uint16_t distances[POINT_COUNT]; // 0 = no valid point; only the latest sample per angle.
int angle = MIN_ANGLE, direction = STEP_ANGLE;
Servo scanner;
Adafruit_SSD1306 display(128, 64, &Wire, -1);
bool oledReady = false;

float measureCm() {
  digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000UL);
  if (!duration) return -1.0f;
  float cm = duration * 0.0343f / 2.0f;
  return (cm >= 2.0f && cm <= 400.0f) ? cm : -1.0f;
}

void drawScan(float cm) {
  if (!oledReady) return;
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.print(angle); display.print(F(" deg "));
  if (cm < 0) display.print(F("--")); else display.print(cm, 0);
  display.print(F("cm"));
  // Origin at (64,63); arcs are clipped at the bottom of the display.
  display.drawCircle(64, 63, 45, SSD1306_WHITE);
  display.drawCircle(64, 63, 22, SSD1306_WHITE);
  display.drawLine(19, 63, 109, 63, SSD1306_WHITE);
  for (uint8_t i = 0; i < POINT_COUNT; i++) {
    if (!distances[i]) continue;
    float a = (MIN_ANGLE + i * STEP_ANGLE) * DEG_TO_RAD;
    float r = distances[i] * RADIUS_PX / RANGE_CM;
    int x = 64 + X_DIRECTION * lroundf(r * cos(a));
    int y = 63 - lroundf(r * sin(a));
    display.fillCircle(x, y, 1, SSD1306_WHITE);
  }
  float a = angle * DEG_TO_RAD;
  display.drawLine(64, 63, 64 + X_DIRECTION * lroundf(RADIUS_PX * cos(a)),
                   63 - lroundf(RADIUS_PX * sin(a)), SSD1306_WHITE);
  display.display();
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT); pinMode(ECHO_PIN, INPUT);
  digitalWrite(TRIG_PIN, LOW);
  Serial.begin(115200);
  Wire.begin();
  Wire.beginTransmission(OLED_ADDRESS);
  oledReady = Wire.endTransmission() == 0;
  if (oledReady) oledReady = display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDRESS);
  if (!oledReady) Serial.println(F("OLED unavailable; serial output remains active."));
  scanner.attach(SERVO_PIN);
  scanner.write(90); // Fit the sensor facing forward at this position, with power off.
  delay(1500);
  scanner.write(MIN_ANGLE);
  delay(600); // Let the first large movement settle.
  Serial.println(F("angle_deg,distance_cm"));
}

void loop() {
  scanner.write(angle);
  delay(120); // Settle the mechanism; also separates ultrasonic bursts.
  float cm = measureCm();
  uint8_t index = (angle - MIN_ANGLE) / STEP_ANGLE;
  distances[index] = (cm >= 2 && cm <= RANGE_CM) ? (uint16_t)(cm + 0.5f) : 0;
  Serial.print(angle); Serial.print(','); Serial.println(cm, 1);
  drawScan(cm);
  if (angle >= MAX_ANGLE) direction = -STEP_ANGLE;
  if (angle <= MIN_ANGLE) direction = STEP_ANGLE;
  angle += direction;
}

3. Co znamená bod na displeji

Senzor je na displeji v bodě (64, 63). Vnější oblouk znamená 100 cm, vnitřní přibližně 50 cm. V obou osách platí stejné měřítko 45 pixelů / 100 cm. Pro úhel α a vzdálenost d program počítá x = 64 + d × 0,45 × cos α a y = 63 − d × 0,45 × sin α. Při 90° je bod přímo nad senzorem.

Parametr RANGE_CM mění rozsah mapy. Vzdálenější platné měření se vypíše číselně, ale v mapě se nekreslí. Bez odrazu se zobrazí -- a v seriových datech -1. Pokud mechanika otáčí senzor zrcadlově, změň X_DIRECTION z 1 na -1 a znovu ověř levou a pravou stranu.

4. Ověř měřítko a směr

  1. Polož pevný předmět dopředu, přibližně 50 cm od osy senzoru. U 90° má bod ležet poblíž vnitřního oblouku.
  2. Přesuň předmět doleva a doprava. Pokud je obraz převrácený, uprav X_DIRECTION.
  3. Odstraň překážku. Původní bod má zmizet po dalším změření stejného úhlu.
  4. Porovnej objekt v 50 a 100 cm. Vzdálenost bodu od středu mapy se má přibližně zdvojnásobit.
  5. Při cukání nebo nárazu do dorazu odpoj napájení a uprav uchycení, rozsah úhlů nebo napájení.

Co zkusit dál

Zkus jiný rozsah RANGE_CM, delší čekání po pohybu nebo export řádků úhel,vzdálenost ze Seriového monitoru. Porovnej hladkou stěnu, židli a látku. Než budeš mapu zpřesňovat, rozliš chybu měření vzdálenosti, vůli serva a šířku zvukového svazku.
