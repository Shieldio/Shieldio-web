POSTAV S RED

Zvířátko na displeji

Kočka spí, stiskem tlačítka se rozveselí a druhým přivoláš psa. Vyzkoušej podmínky, vstupy a OLED s knihovnou ShieldioDisplay 0.3.0.

Potřebuješ: sestavenou RED s Nano, OLED SSD1306 128 × 64, dvě tlačítka a datový USB kabel. Senzor ani servo pro základní projekt nepotřebuješ.

1. Zkontroluj zapojení

Tlačítko 1 → D11 · tlačítko 2 → D12. Na RED mají externí pull-up rezistory; stisk znamená LOW. OLED: SDA → A4, SCL → A5, adresa 0x3C. Před připojením odpoj napájení a ověř GND/VCC podle svého modulu.

2. Otevři připravený program

Začni bloky a zvol Spustit na desce. Pod Shieldio RED použij kategorii Tlačítka a v kategorii Displej sekci Zvířátka. Knihovna ShieldioDisplay 0.3.0 je přibalená automaticky. C++ varianta otevře pokročilý režim, má stejné chování a překresluje jen při změně.

Zobrazit celý program
// Shieldio RED: OLED SSD1306 128x64, SDA A4 / SCL A5, address 0x3C.
// Buttons D11/D12 have external pull-ups on RED; pressed = LOW.
#include <ShieldioDisplay.h>
ShieldioDisplay display;
using Animal = ShieldioDisplay::Animal;
using Mood = ShieldioDisplay::Mood;
Animal shownAnimal = Animal::Cat;
Mood shownMood = Mood::Sleepy;

void setup() {
  pinMode(11, INPUT);
  pinMode(12, INPUT);
  display.begin();
  display.face(shownAnimal, shownMood);
}

void loop() {
  // Button 2 has priority, matching the block starter.
  bool second = digitalRead(12) == LOW;
  bool first = digitalRead(11) == LOW;
  Animal animal = second ? Animal::Dog : Animal::Cat;
  Mood mood = second ? Mood::Surprised : first ? Mood::Happy : Mood::Sleepy;
  if (animal != shownAnimal || mood != shownMood) {
    display.face(animal, mood);
    shownAnimal = animal;
    shownMood = mood;
  }
  delay(100);
}

3. Ověř všechny stavy

  1. Po úvodním logu bez stisku uvidíš ospalou kočku.
  2. Drž tlačítko 1: kočka je veselá. Po uvolnění zase spí.
  3. Drž tlačítko 2: zobrazí se překvapený pes.
  4. Stiskni obě: druhé tlačítko má přednost. Najdi v blocích, proč tomu tak je.

4. Dej zvířátku vlastní povahu

Změň psa na lva, vyber jinou z pěti nálad nebo nastav zavřené oči. Pro ruční mrknutí zobraz tvář se zavřenýma očima, počkej 0,15 s a zobraz stejnou tvář s otevřenýma očima. Pak zkus podmínku z tlačítka nahradit platným měřením vzdálenosti.

Když se nedaří

Prázdný displej? Ověř SDA/A4, SCL/A5, napájení a adresu 0x3C. Nereaguje tlačítko? Ověř D11/D12 a stisk LOW. Funkce face() nahradí celý displej ihned; další render() nepotřebuje. Zvířecí tváře byly ověřené na OLED, tento nový projekt ještě potřebuje ověřit na tvé desce.
