POSTAV S RED

Digitální metr

Změř vzdálenost pomocí zvuku a zobraz ji na OLED. Začni jedním senzorem, jedním vzorcem a několika kontrolními měřeními.

ZapojeníProgramOvěřeníPřehled součástek

Potřebuješ: sestavenou RED s Nano, HC-SR04, OLED SSD1306 128 × 64 a datový USB kabel. Servo není potřeba. Počítej orientačně s 20–30 minutami; ukázkový program je určený k ověření na tvé desce.

1. Zkontroluj zapojení

Shieldio RED
ModulSignály
HC-SR04VCC → 5 V · GND → GND · TRIG → D7 · ECHO → D8
OLED SSD1306SDA → A4 · SCL → A5 · VCC/GND

Na sestavené RED jsou signály propojené cestami na PCB. Použij označené patice; vodiče navíc potřebuje až otočný senzor radaru. Moduly připojuj s odpojeným napájením a ověř pořadí vývodů, zvlášť GND/VCC u OLED.

2. Spočítej cestu tam i zpět

Senzor změří čas od vyslání zvuku po návrat odrazu. Zvuk urazil vzdálenost dvakrát, proto dělíme dvěma: d = t × c / 2. Pro čas v mikrosekundách a rychlost zvuku přibližně 343 m/s při pokojové teplotě dostaneš d [cm] = t [µs] × 0,0343 / 2.

Příklad: odraz za 1 000 µs znamená přibližně 17,15 cm. Desetinné místo na displeji není zárukou milimetrové přesnosti. Výsledek ovlivňuje teplota, sklon, velikost a materiál překážky.

3. Nahraj program

Klikni na Otevřít program v editoru. Ukázka otevře Arduino C++ v pokročilém režimu; ponech desku Shieldio RED, vyber USB port a nahraj ji. Adafruit GFX a SSD1306 jsou přibalené, OLED má 128 × 64 bodů a adresu 0x3C. Vestavěný monitor a plotter nastav na 115200 baud, jak uvádí program. Editor při nahrávání spojení uvolní a příjem obnoví. Případný monitor v jiné aplikaci před nahráváním zavři.

Program provede tři měření s odstupem nejméně 65 ms a zobrazí jejich prostřední hodnotu (medián). Pokud některý odraz nepřijde do 30 ms nebo je mimo rozsah 2–400 cm, zobrazí -- cm. Chybějící odraz se nesmí tvářit jako vzdálenost nula.

Zobrazit celý program
// Shieldio RED: HC-SR04 distance meter, SSD1306 128x64 I2C OLED.
// Pin map follows the RED block editor. Check your PCB revision.
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

const uint8_t TRIG_PIN = 7;
const uint8_t ECHO_PIN = 8;
const uint8_t OLED_ADDRESS = 0x3C;
const float SOUND_CM_PER_US = 0.0343f; // Approximation near 20 degrees C.
Adafruit_SSD1306 display(128, 64, &Wire, -1);
bool oledReady = false;

float measureCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000UL);
  if (duration == 0) return -1.0f; // No echo is not zero distance.
  float cm = duration * SOUND_CM_PER_US / 2.0f;
  return (cm >= 2.0f && cm <= 400.0f) ? cm : -1.0f;
}

float medianCm() {
  float readings[3];
  for (uint8_t i = 0; i < 3; i++) {
    readings[i] = measureCm();
    delay(65); // Separate ultrasonic bursts by more than 60 ms.
  }
  // Keep a missing echo visible instead of averaging it into a distance.
  for (uint8_t i = 0; i < 3; i++) if (readings[i] < 0) return -1.0f;
  if (readings[0] > readings[1]) { float t = readings[0]; readings[0] = readings[1]; readings[1] = t; }
  if (readings[1] > readings[2]) { float t = readings[1]; readings[1] = readings[2]; readings[2] = t; }
  if (readings[0] > readings[1]) { float t = readings[0]; readings[0] = readings[1]; readings[1] = t; }
  return readings[1];
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  digitalWrite(TRIG_PIN, LOW);
  Serial.begin(115200);
  Wire.begin();
  Wire.beginTransmission(OLED_ADDRESS);
  oledReady = Wire.endTransmission() == 0;
  if (oledReady) oledReady = display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDRESS);
  if (!oledReady) Serial.println(F("OLED unavailable; check power, SDA=A4, SCL=A5 and address."));
  if (oledReady) { display.clearDisplay(); display.display(); }
}

void loop() {
  float cm = medianCm();
  if (cm < 0) Serial.println(F("No valid echo"));
  else { Serial.print(cm, 1); Serial.println(F(" cm")); }
  if (!oledReady) return;
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.print(F("SHIELDIO / METR"));
  display.setCursor(0, 24);
  display.setTextSize(2);
  if (cm < 0) display.print(F("-- cm"));
  else { display.print(cm, 1); display.print(F(" cm")); }
  display.setTextSize(1);
  display.setCursor(0, 52);
  display.print(cm < 0 ? F("Bez platneho odrazu") : F("Od cela senzoru"));
  display.display();
}

4. Porovnej výsledek s pravítkem

  1. Postav rovnou pevnou překážku kolmo k senzoru. Vzdálenost měř od čela senzoru, ne od zadní hrany desky.
  2. Vyzkoušej 10, 30 a 50 cm. Pro každou vzdálenost si zapiš několik údajů z displeje a rozdíl proti pravítku.
  3. Otoč senzor do volného prostoru. Bez platného odrazu očekávej -- cm, nikoli 0 cm.
  4. Zkus šikmou plochu nebo látku. Vysvětli, proč může odraz zeslábnout nebo zmizet.

Když se nedaří

Prázdný OLED: zkontroluj GND/VCC, SDA=A4, SCL=A5 a adresu displeje (některé moduly mají 0x3D). Naměřená hodnota se vypisuje i do Seriového monitoru.
Stále -- cm: ověř D7/TRIG a D8/ECHO, společnou zem a zkus větší tvrdý předmět 20–50 cm před senzorem.
Skákající hodnoty: zpevni uchycení, natoč plochu kolmo a vypni další ultrazvukové senzory v okolí.
