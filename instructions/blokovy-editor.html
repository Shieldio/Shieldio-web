Prototyp

Blokový editor pro RED.

Poskládej program z bloků, vpravo se ti rovnou generuje skutečný Arduino C++ kód. Piny odpovídají popiskům přímo na desce RED. Tohle je časný test, kód si zatím musíš nahrát přes Arduino IDE ručně, přímé nahrávání z prohlížeče tu není.


      

    

  






  

    

      Co tenhle prototyp neumí (zatím)
      
Knihovny pro OLED se do kódu přidají jen tehdy, když použiješ blok displeje. Tlačítka na RED využívají externí pull-up rezistory, proto editor nastaví vstupy jako INPUT a stisk čte jako LOW. Rozpracované bloky si můžeš uložit do souboru a později znovu načíst. Přímé nahrávání do desky z prohlížeče zatím není dostupné; hotový .ino soubor nahraj přes Arduino IDE.
